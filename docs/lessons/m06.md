# 把同一目标带到下一轮

恢复审计包含三个工作阶段：先调查，再评分，最后清理实验并提交。把它们分成多个轮次（Round），页面就能持续回答“做到哪了”“为什么继续”和“为什么停止”。

`LongTaskRunner` 保存目标、当前状态、已经开始的轮数和上限。每轮调用同一个智能体，并共享运行上下文、上下文投影和会话日志。目标与轮次变化也写入事件流，因此跨轮进度可以回到完整时间线中。

续行依赖实际证据：调查轮要读到事故包，评分轮要得到评分结果，提交轮要通过验证并卸载临时插件。若一轮已经产生具体进展，却还缺少指定结果，协调器最多追加一次明确的补充指令。补充后仍无进展会进入 `blocked`；达到轮数上限会进入 `max-rounds`；成功提交则进入 `completed`。

实现范围保持在单进程教学场景：同一任务可以跨轮继续，每次继续都要有证据，停止时也会留下可读原因。
