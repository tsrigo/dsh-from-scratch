# 给每项能力一个主人

工具数组已经能工作，但它没有记录来源，也无法说明卸载时需要清理哪些服务、提示词和监听器。安装中途报错时，半完成状态也可能留在运行进程里。

运行上下文（Context）给每个插件一段 `setup()` 安装期。插件在这段时间贡献服务、工具、提示词片段和事件监听器；每次登记都会同时保存一项清理动作。安装失败或主动卸载时，清理动作按相反顺序执行，而且每个卸载函数只生效一次。

事故场景由三块能力组装：模型插件提供 `Llm` 服务，状态插件保存提交状态，事故插件提供两个工具、一段规则提示词和一个监听器。`inspect()` 会列出每项能力的归属与服务依赖，页面据此绘制能力图。

预设配置（preset）可以封装一组插件选择：标准模式提供完整编码能力，PTC 更换工具呈现方式，极简模式删减工具，创造模式增加检查、实验和创作指导。本教程展示组装原理，没有实现预设配置加载器。
