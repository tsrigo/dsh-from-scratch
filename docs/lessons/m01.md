# 从一次工具往返开始

Agent Harness（智能体运行框架）负责整理模型输入、执行工具并保存过程。大语言模型（Large Language Model，LLM）负责选择下一步：直接回答，或提出一个工具调用。

一次用户交互称为一轮（turn），轮内每次“整理请求—等待模型—执行工具”称为一步（step）。`Agent` 会把系统规则、已有消息、工具参数规则和本步说明装进请求，再交给统一的 `Llm` 接口。模型返回工具名与参数后，Ajv（一个 JSON 结构校验库）先检查参数，运行框架随后串行执行工具，并把结果加入下一步请求。

火星事故包只开放两个动作：读取固定数据、提交固定结构的方案。确定性模型模拟器会稳定完成读取、提交和收尾三步；DeepSeek 适配层也使用同一套请求格式。循环逻辑始终留在运行框架内。

## 两种工具呈现方式

标准模式逐项展示工具说明，模型每次返回普通工具调用。程序化工具调用（Programmatic Tool Calling，PTC）则提供 Code Mode 软件开发工具包（Software Development Kit，SDK），让模型用一小段 TypeScript 组合循环、条件和多个工具。本教程运行标准模式；页面中的 PTC 程序仅用于理解呈现差异。
