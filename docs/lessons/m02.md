# 把模型请求拆成四个区域

模型请求（Model Request）是每次交给模型的一份工作包。它包含系统规则、可用工具、此前对话和本步说明。一次用户交互可能连续产生多份模型请求。

执行记录需要保存原文，发送给模型的上下文可以按规则裁剪。`context.ts` 把请求排成四个区域：稳定的系统提示词、稳定的工具参数规则、持续追加的消息、本步变化的动态说明。工具结果超过阈值时，投影只保留头尾，并插入带省略字符数的标记。

Token（文本计量单位）用于粗略衡量模型输入长度。页面按字符数给出教学估算，适合观察相对变化；它没有调用模型服务的精确计数器。`compareRequestPrefix()` 还会找出相邻请求从开头起相同的部分，帮助解释提示词缓存（Prompt Cache）可能复用哪一段输入。页面不会把估算当成实际缓存命中。

动态说明被放在请求末尾，因此稳定规则、工具说明和已有消息会尽量留在前面。安装插件、改变工具目录或建立上下文摘要点时，相同前缀会缩短；请求面板会标出变化从哪里开始。
