# M02 · 请求不是一个大字符串

上一章已经能完成任务，但第二次请求会把整段遥测原样带回模型。执行记录和模型上下文不是一回事：前者要完整，后者要克制。

`context.ts` 把统一请求展开成有序部件：稳定的 system prompt、稳定的 tool schemas、只追加的消息、最后才是 step 特有动态上下文。工具结果超过阈值时，投影保留头尾并插入明确的省略标记。M02 还没有 Session Log，所以原始结果暂时仍留在 Agent 的内存历史；M04 会消除这份隐藏历史。

网站使用同一个 `describeRequest()` 计算各部分的近似 token。算法只是字符数除以四，目的是看相对变化，不是 tokenizer，也不是 provider usage。`compareRequestPrefix()` 对相邻请求的规范化部件做最长前缀比较：它能告诉我们变化从哪里开始，却绝不声称 DeepSeek 真的命中了 Prompt Cache。

这里有个刻意的顺序：动态上下文放在追加历史之后。这样稳定 prompt、schema 和已经发生的消息尽量留在前面。安装插件、改变工具目录或建立摘要检查点时，失效位置会自然前移——后面几章的网站会把它画出来。
